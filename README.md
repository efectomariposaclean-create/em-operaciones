# Efecto Mariposa · Operaciones

App de control de servicios, calidad, incidencias y jornada de Efecto Mariposa Clean & Care.

- La app (esta carpeta) se publica con GitHub Pages.
- El servidor está en `servidor/`: es Google Apps Script, y los datos se guardan en el Drive de la empresa.

Aquí no hay datos de clientes ni contraseñas. El acceso se hace con un PIN personal.
